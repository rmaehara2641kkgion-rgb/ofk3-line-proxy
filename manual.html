システム概要

OFK3 配送管理システムは、Amazon ラストマイル配送ステーションの日次オペレーションを一元管理するWebアプリケーションです。点呼・配車・品質・経営分析までを単一プラットフォームで運用し、管理業務の効率化と配送品質の向上を実現します。

点呼照合（シフト整合チェック）

DAシフト表とAmazonスケジュールUIを自動照合し、差異を検出します。

  • 点呼済: QR + メンター認証が両方完了
  • 未点呼: シフトにいるが未認証
  • 臨時点呼: シフト外の臨時ドライバー
  • シフト差異: スケジュールUI との不整合

月次シフト集計・CSV出力にも対応しています。

配送オペレーション管理

Amazon アサインデータ（xlsx）を取り込み、当日の全ルート・ドライバーの配送状況をリアルタイムで一覧表示します。

ダッシュボード表示項目

  • ドライバー名（LINEプロフィール写真付き）
  • コース番号・配送個数
  • 配送完了予測時間（能力値ベース自動計算）
  • ステータス（シフト別色分け）

配送完了予測の計算ロジック

要素内容
① 積み込み時間固定値: 15分
② 往路移動時間ステーション → 最初の配送先
③ 配達時間荷物件数 ÷ 能力値（個/h）
④ 復路移動時間最後の配送先 → ステーション
予測終了時間 = 出発時間 + 積込15分 + 往路 + 配達時間 + 復路

時間指定荷物の管理

アサインデータから時間指定荷物を自動抽出し、ドライバー別に一覧表示します。

物量管理・推移分析

サイクルデータを蓄積し、日別の個口数・件数・コース数・台数の推移をグラフ化します。ZIP内のxlsxも自動展開して読み込みます。

ドライバーのLINEに届く配送MAPはスマホでスワイプ操作（拡大・移動）が可能です。ピンタップで詳細も確認できます。未配達（赤）/ 完了（緑）/ 現在地（青）で色分け表示されます。

データ同期

ローカル（ブラウザ localStorage）と GAS サーバー（Google スプレッドシート）間で双方向同期が可能です。

  • PC → サーバー同期: ローカルのマスタを GAS に送信
  • サーバー → PC 取得: GAS からマスタを取得しローカルを更新
  • CSV エクスポート: 全マスタデータの CSV ダウンロード

ドライバー名前解決・同一人物統合 Phase 4.4

Amazon の配送データでは同一ドライバーが異なる名前表記で登場することがあります。本システムは自動検出・統合機能でこの問題を解決します。

課題の具体例

シフト表名Amazon アサイン名検出パターン
晴樹 藤永晴樹 藤永晴樹 藤永Amazon名変則（部分一致）
健士朗 脇山健士朗 脇山 脇山Amazon名変則（末尾姓重複）

名前解決エンジン（resolveDriverKey）

8段階の名前解決アルゴリズムで、入力名を正キーに自動変換します。

  1. 別名マップ照合
  2. サフィックス除去（OHRE等）
  3. 直接一致（driverDB）
  4. 空白除去一致
  5. 姓名反転一致
  6. Transport ID 逆引き
  7. 日本語名 逆引き
  8. フォールバック（元の名前）

同一人物候補 UI

検出された候補ペアを一覧表示し、管理者が「どちらを正キーに残すか」を選択できます。

  • 各ペアに LINE 連携バッジ（✔ / ✘）と TID バッジを表示
  • 推奨方向を自動判定（Amazon取込名・能力DB実績等に基づく）
  • 「名前Aを残す」「名前Bを残す（推奨）」の2ボタン式
  • TID一致候補は推奨方向で一括統合も可能

推奨判定の優先順位（pickCanonical）

  1. 能力DB（driverDB）に実績データがある方
  2. LINE連携 または TID が片方のみにある方
  3. Amazon アサインデータに含まれる名前
  4. Amazon名変則ペアの場合、長い方（Amazon取込名）
  5. OHREサフィックスなし側
  6. 短い方（フォールバック）
運用効果: 同一人物の重複登録を自動検出し、ワンクリックで統合。LINE・TID・電話番号が正キー側に自動移行されるため、手動での紐付け修正が不要です。

退職者管理 Phase 4.5

退職したドライバーをマスタから永続的に非表示にしつつ、能力DBの過去実績は保持する仕組みです。

退職者削除の動作

対象動作
マスタ管理非表示化（「退職者N名非表示」と表示）
能力DB実績データは保持（過去履歴として残存）
ページリロードlocalStorage に永続化済み。復活しない
サーバー同期退職者は GAS に送信されない
サーバー取得GAS からの読込時も退職者は復活しない
CSV エクスポート退職者は含まれない

誤削除時の復元

「退職者」ボタンから退職者リストを表示し、個別または全員を復元できます。復元後は LINE・TID 等の再紐付けが必要です。

品質管理（FTDS / CC / DNR / LAT）

Amazon の品質指標を帳票照合し、エクスポートする機能です。

指標正式名称内容
FTDSFirst Time Delivery Success初回配達成功率
CCCustomer Complaint顧客苦情件数
DNRDelivery Not Received未受領申告
LATLate Delivery遅延配送

各帳票を xlsx でアップロードし、照合結果をエクスポート（CSV）できます。台数照合機能により、車両台数とシフトの整合性チェックも行えます。

仕分けスキャン

バーコードリーダーで荷物のDA番号をスキャンするだけで、コース番号を即時判定・音声読み上げします。

従来比較

従来（手作業）OFK3 仕分けスキャン
手順Excel → Ctrl+F → DA番号入力 → 目視確認スキャン1回で即コース表示
所要時間1件あたり 15〜30秒1件あたり 1〜2秒
ミス率目視のため一定のミスリスクシステム判定でミスゼロ
音声案内: コース番号を音声で読み上げるため、荷物から目を離さずに仕分け作業が可能です。
